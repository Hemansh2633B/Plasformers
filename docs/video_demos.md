# Video Demo Scripts

Suggested demos:

1. Drag-and-drop image detection with `plas web`.
2. TensorRT export with `plas export tensorrt`.
3. REST batch inference with `plas serve`.
4. Tracking and zone counting with `plas track`.
5. Grad-CAM inspection with `plas explain`.

Recordings should show command invocations, FPS, output artifacts, and hardware.
